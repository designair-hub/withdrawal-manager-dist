# Elállási Űrlap – kiadások

Az **Elállási Űrlap – Interaktív elálláskezelő WooCommerce-hez** bővítmény publikus kiadási csatornája.
A bővítmény ezt a repót figyeli az új kiadásokért, és a WordPress szokásos frissítési felületén
(*Bővítmények* / *Irányítópult → Frissítések*) kínálja fel őket.

A kiadások automatikusan készülnek a (privát) forrás repóból – ide ne commitolj kézzel.

Kézi telepítés: töltsd le az `elallasi-urlap.zip` fájlt a legfrissebb
[kiadásból](../../releases/latest), majd töltsd fel a *Bővítmények → Új hozzáadása → Bővítmény feltöltése* menüben.
